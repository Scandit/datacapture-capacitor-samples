# Id Capture Simple Sample

This sample demonstrates the basic functionality of the ID Capture API. It shows how to scan and extract data from identity documents such as passports, driver's licenses, and ID cards.

## Created with Capacitor Create

This app was created using the `npx @capacitor/cli create` command, and comes with a very
minimal shell for building an app.

Note: unless you know what you're doing, we don't recommend using the `create` way of building an app. Instead, you'll
likely want to create an app using your framework's tooling (such as `create-react-app`), and then _add_ capacitor
to _that_ project (using `npx @capacitor/cli init`).
